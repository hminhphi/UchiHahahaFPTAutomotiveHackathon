# UchiHahaha - FleetIQ Guardian R2 Submission Package

This directory is the ready-to-complete upload package for Automotive Hackathon Round 2.

Included now:

- `PREDICTIONS/UchiHahaha/`: ten validated blind-test CSVs, `T01d.csv` through `T10d.csv`.
- `EVALUATION/`: official organizer evaluator outputs for the full-GT `T01-Sample` practice trip.
- `REPORT/FINAL_REPORT_R2.md`: final report source draft with evidence references and limitations.
- `MANUAL_SUBMISSION_CHECKLIST.md`: final operator checklist.

Add before upload:

1. Confirm the official team lead and email in the report, then export it as `REPORT/FINAL_REPORT_R2.pdf` if the portal requires PDF.
2. Add the unedited or transparently disclosed demo recording to `VIDEO_DROP_HERE/` and paste a reviewer-accessible link in the report.
3. Add required screenshots, final slide deck/PDF, and external evidence links to their marked directories.
4. Follow `MANUAL_SUBMISSION_CHECKLIST.md`; it distinguishes verified facts from items that need team confirmation.

The archive deliberately does not claim organizer-scored accuracy for redacted T01d-T10d trips.
