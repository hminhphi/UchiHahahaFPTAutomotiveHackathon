# Practice Evaluation Evidence

Included evidence is from the organizer's `evaluation.py` on the full-ground-truth `T01-Sample` practice trip:

- `T01-Sample_baseline_evaluation.json`: organizer SGBM TTC baseline.
- `T01-Sample_custom_evaluation.json`: FleetIQ custom detector plus depth-ROI TTC path.
- `T01-Sample_custom_predictions.csv`: organizer-format Practice prediction used by the custom evaluation.

This directory is validation evidence only. It is not a replacement for the ten scored-trip CSVs and must not be presented as blind-test accuracy.
